## About me

I'm Hariohm. I work on computer vision and deep learning, with a particular interest in healthcare applications. I enjoy turning experiments into reproducible pipelines and building software that works beyond a notebook.

My projects span sclera segmentation, human pose estimation, and embedded development, alongside app and backend development.

## Selected projects

### Computer vision & research

- **[ShapeGAN-DLV3](https://github.com/HariohmBhatt/ShapeGAN-DLV3)** — A two-stage sclera segmentation pipeline with synthetic pretraining, mixed-domain finetuning, reproducible experiment configs, and evaluation tools. `Python` `PyTorch`
- **[MMPose Bharatnatyam](https://github.com/HariohmBhatt/MMPOSE-bharatnatyam)** — Real-time pose estimation for Indian classical dance using MMPose and HRNet. Includes setup and environment replication guides. `Python` `MMPose`
- **[SSBC 2026 Stage 1 Lab](https://github.com/HariohmBhatt/SSBC2026)** — An engineering scaffold for repeatable segmentation experiments, dataset manifests, and evaluation workflows. Model training is a planned next step. `Python`

### Embedded systems

- **[NooVa](https://github.com/HariohmBhatt/NooVa)** — ESP32-S3 touchscreen firmware with local diagnostics, Wi-Fi setup, SSH commands, and OTA updates. `C++17` `Arduino` `PlatformIO`
